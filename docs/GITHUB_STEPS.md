# Завантаження етапу ЛР16

1. Відкрийте https://github.com/LitruzZz/course-monitoring-python-2026.
2. Розпакуйте ZIP ЛР16 і відкрийте course_monitoring.
3. Add file → Upload files: перетягніть вміст папки, оновивши наявні файли.
4. Не завантажуйте ZIP одним файлом. manage.py має лишатися в корені.
   Обов’язково додайте monitoring/migrations/0001_initial.py і .gitignore.
5. Назва коміту: ЛР16 — Device, пошук та адміністрування.
6. Відкрийте створений коміт через його короткий хеш над списком файлів
   або список комітів. Скопіюйте повну адресу /commit/... .
7. Надішліть її в чат для заповнення Word або вставте самостійно.

Другий репозиторій не потрібний. База, середовище, кеші та робочі паролі
в ZIP не включені. Дані відновлюються міграціями та навчальною фікстурою.
